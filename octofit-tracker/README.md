# OctoFit Tracker

This repository contains the OctoFit Tracker example app scaffolded as a modern multi-tier application.

- Frontend: Vite + React 19 (port 5173)
- Backend: Node + Express + TypeScript + Mongoose (port 8000)
- MongoDB: default port 27017 (database: octofit)

To run locally:

1. Start MongoDB (default listens on 27017)
2. Backend:
   - cd octofit-tracker/backend
   - npm install
   - npm run dev
3. Frontend:
   - cd octofit-tracker/frontend
   - npm install
   - npm run dev
